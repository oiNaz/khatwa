# Contributing

1. Install Node.js 20+ and run `npm install`.
2. Start the app with `npm run dev`.
3. Before proposing changes, run `npm test`, `npm run lint`, and `npm run build`.
4. Keep user data local. Do not add network calls that transmit tasks, notes, focus history, or settings.
5. Add tests for data transformations, timer transitions, import validation, and persistence behavior.

Use small, focused changes and describe any storage schema change and its migration impact in the pull request.
